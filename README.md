# 🌿 ImpiloYesizwe Care Community Project

A modern, responsive NGO website built with **ASP.NET Core MVC** to support the online presence of the **ImpiloYesizwe Care Community Project**.

## 📖 About

The ImpiloYesizwe Care Community Project is a community-based non-profit organisation committed to improving the lives of vulnerable children, families and communities through healthcare, education and social support.

This project aims to provide a professional website where visitors can:

- Learn about the organisation
- View available services
- Browse the gallery
- Contact the organisation
- Support the NGO through donations
