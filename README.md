# ImpiloYesizwe Care Community Project

## Overview
ImpiloYesizwe Care Community Project is an ASP.NET Core MVC web application developed to help manage an NGO's online presence. The system allows visitors to contact the organization, make donations, and view services and gallery images. Administrators can securely manage the website through a protected dashboard.

## Features
- Home page
- About page
- Services
- Gallery
- Contact form
- Donation form
- Admin dashboard
- Secure admin login (BCrypt password hashing)
- Manage services
- Manage gallery
- View contact messages
- View donations

## Technologies
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap 5
- BCrypt.Net

## Getting Started

1. Clone the repository.
2. Update the SQL Server connection string in `appsettings.json`.
3. Run the database migrations or create the database.
4. Start the application.
